# 🎵 Noor Music Player

A modern, responsive, and interactive **Music Player Website** built with **HTML, CSS, and JavaScript**.

The website provides a clean and professional music-listening interface where users can browse songs, search for music, control playback, adjust volume, mark favorites, and filter songs by category.

---

## ✨ Features

* 🎧 Modern and professional music player interface
* 🎵 Play and pause music
* ⏮️ Previous and next song controls
* 🔀 Shuffle functionality
* ❤️ Favorite button
* 🔊 Volume control
* ⏱️ Music progress bar with current time and duration
* 🔎 Search songs by title or artist
* 📂 Music categories:

  * All Music
  * Pop
  * Chill
  * Rock
  * Classical
* 📱 Fully responsive design
* 💿 Animated vinyl-style album artwork
* 🎨 Modern dark UI with lavender and pink accents
* 📋 Dynamic playlist
* 🚫 No-results message when music is not found
* 🎼 Font Awesome icons
* ✨ Smooth and user-friendly interface

---

## 🛠️ Technologies Used

### Frontend

* **HTML5** – Website structure
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Music player functionality and user interactions

### External Resources

* **Google Fonts – Poppins**
* **Font Awesome 6.7.2** – Icons

## 🎨 Website Sections

### 1. Sidebar Navigation

The sidebar contains:

* NOOR Music Player logo
* Home
* Browse
* Favorites
* Music categories
* A small music message section

### 2. Welcome Header

The main content starts with a welcome message and a search bar that allows users to find songs quickly.

### 3. Now Playing Section

The Now Playing section displays:

* Album artwork
* Current song title
* Artist name
* Music progress
* Current playback time
* Total duration
* Player controls
* Volume control

### 4. Playlist

The playlist dynamically displays available songs along with their information.

Users can select a song from the playlist to start playing it.

### 5. Search & Categories

Users can search for music and filter songs according to different categories such as Pop, Chill, Rock, and Classical.

## ⚙️ How to Run the Project

1. Download or clone this repository.

2. Open the project folder.

3. Make sure the following files are present:

```text
index.html
style.css
script.js
```

4. Add your music files inside the `music` folder.

5. Open `index.html` in your web browser.

6. Start listening to your music 🎧
